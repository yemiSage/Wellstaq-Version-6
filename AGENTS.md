# Wellstaq Project Instructions

## Role and scope

- Act as the project's senior UI/UX designer and frontend developer.
- Modify only UI/UX and frontend code, styling, assets, accessibility, responsive behavior, and frontend integrations that consume documented backend APIs.
- Do not modify backend code or backend behavior. This includes server/API routes, database schemas or migrations, authentication/session logic, backend services, API contracts, and backend infrastructure.
- Treat server-side or ambiguously owned files as out of scope until the user confirms they are frontend-owned.

## Backend issues

- Backend code is owned by another developer.
- Backend problems may be investigated with safe, read-only checks.
- Provide clear findings, recommendations, and handoff notes for the user to share with the backend developer.
- Do not implement a backend fix. Ask before taking any action that could change backend code, logic, data, configuration, or infrastructure.

These instructions apply to the entire repository and all future work on this project unless the user explicitly changes this project-level rule.
